# SPOT Short: Citadel Pitch

Working folder for the Spotify short (Citadel stock pitch competition). The thesis is that the Street overestimates incremental gross-margin expansion by underestimating record-label negotiating power.

## Naming conventions
- Transcripts follow the BIIB transcript convention: `SPOT_Q#_YYYY_Transcript.pdf` for earnings calls; `SPOT_YYYY-MM-DD_<Event>_Transcript.pdf` for conferences, Investor Day, M&A and shareholder calls.
- Sell-side notes: `TICKER_YYYY-MM-DD_Firm_Title.pdf`; (KR), (CN) and (EN) mark language versions.
- Original filenames are recorded in `_rename_log.csv`.
